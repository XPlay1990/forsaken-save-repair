# Third-party code

Runtime libraries are pinned, bundled with this site, and never fetched from a CDN:

- pako 2.1.0: https://github.com/nodeca/pako — MIT and zlib licenses; see vendor/pako-LICENSE.txt.
- fflate 0.8.2: https://github.com/101arrowz/fflate — MIT license; see vendor/fflate-LICENSE.txt.

Warcraft III and Forsaken Kingdom are Blizzard game names. This project is an
unofficial community tool and distributes no game archives or player save data.
