# Third-party code

Runtime libraries are pinned, bundled with this site, and never fetched from a CDN:

- pako 2.1.0: https://github.com/nodeca/pako — MIT and zlib licenses; see vendor/pako-LICENSE.txt.
- fflate 0.8.3: https://github.com/101arrowz/fflate — MIT license; see vendor/fflate-LICENSE.txt.

This is an unofficial community tool for Warcraft III's Forsaken Kingdom
campaign. It distributes no game archives or player save data.
